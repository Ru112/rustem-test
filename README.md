# Project Supernatural

A mobile-first static prototype for a calm, privacy-minded community built around one principle:

> Experiences first. Explanations remain open.

## What is included

- Responsive, accessible single-page interface
- Clearly labeled fictional experience previews
- Community response preferences and rules
- A private browser-only draft with autosave and explicit deletion
- A separate, voluntary support area

## What is intentionally not included

No accounts, database, publishing, analytics, tracking, secrets, AI chat, or real user data.

## Run locally

Open `index.html` directly, or serve the folder with any static file server. No build step or dependencies are required.

The draft is stored in browser `localStorage` on the current device. It is never uploaded by this prototype.

## Owner control center

The separate [`control-center`](control-center/) directory contains a staging-only management gateway and mobile owner dashboard. It is excluded from the GitHub Pages artifact and has no real-user launch path.
